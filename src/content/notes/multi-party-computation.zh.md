MPC 让互不信任的多方在私有输入上联合计算一个函数 $f$，使得每一方只获知自己的输出，别无所知。它把「两位将军想知道谁更富有」的问题推广到任意计算。阈值密码学是 MPC 的一个特例：其中的*密钥*被拆分，任何单独一方都无法独自使用。

## 1. 秘密共享

**定义（Shamir $t$-out-of-$n$ 秘密共享）.** 要在 $n$ 方之间共享 $s \in \mathbb{F}_q$，阈值为 $t$，需选择随机多项式
$$ p(x) = s + a_1 x + \dots + a_{t-1} x^{t-1} $$
使 $p(0) = s$，并把份额 $p(i)$ 交给第 $i$ 方。

- **正确性：** 任意 $t$ 个份额都能插值出 $p$（Lagrange），并恢复
  $s = \sum_{i \in T} \lambda_i p(i)$，其中 $\lambda_i$ 是 Lagrange 系数。
- **隐私性：** 少于 $t$ 个份额不会泄露关于 $s$ 的任何信息——对每一个可能的秘密 $s'$，都存在一个与所观察到的份额一致的多项式（完美保密）。

**加法共享**是 $t = n$ 的特例：$s = \sum s_i$。**Shamir 是线性的**，因此秘密共享算术天然可加（各方在本地相加份额）；乘法则需要一轮交互（Beaver 三元组——见下文）。

## 2. 不经意传输与乱码电路

**1-out-of-2 不经意传输（OT）.** 发送方持有 $(m_0, m_1)$；接收方持有比特 $b$ 并获知 $m_b$，而发送方无从得知 $b$，接收方也无从得知 $m_{1-b}$。OT 是一个**完备原语**：有了 OT 就能构造任意 MPC。

**Yao 乱码电路**（两方，常数轮）：
1. 乱码方对电路编码：为每条导线取两个随机标签（$w^0, w^1$）；为每个门生成一张乱码表，用输入标签加密输出标签。
2. 求值方收到乱码电路，并通过 OT 取得自己输入对应的标签，然后逐门求值以获得输出标签。

当电路较浅且通信是瓶颈时，乱码电路效率很高；**GMW**（基于秘密共享，轮复杂度 = 电路深度）与 **BGW/SPDZ 系列**协议（基于算术电路秘密共享并预处理 **Beaver 三元组**）是域上算术运算的替代方案——后者是大规模 MPC 的主力。

**Beaver 三元组.** 预计算的三元组 $(a, b, c)$ 满足 $c = ab$，可在一轮内相乘两个共享值 $[x], [y]$：公开 $[x] - [a]$ 与 $[y] - [b]$，然后
$[xy] = [c] + (x-a)[b] + (y-b)[a] + (x-a)(y-b)$。

## 3. 威胁模型

| 模型 | 敌手占比 | 典型工具 |
|-------|--------------------|---------------|
| 诚实多数（$t < n/2$ 或 $t < n/3$） | 有界 | Shamir/BGW，信息论安全 |
| 不诚实多数 | 最多 $n-1$ | SPDZ、乱码电路、OT（计算安全） |
| 隐蔽 / 中止 | 作恶但害怕被发现 | 较轻量的协议 |
| 自适应 | 随时间选择腐化对象 | 纠删/复杂度开销 |

诚实多数协议可以达到**信息论安全**（不依赖困难性假设）；不诚实多数协议则必须是**计算安全**的（例如依赖 LWE/OT 的困难性）。

## 4. 阈值密码学（NIST）

NIST 的多方阈值密码学项目对如下方案进行标准化：签名/解密密钥被分散，使得 $t$ 方必须合作，而少于 $t$ 方则一无所知。

- **阈值签名：** 密钥 $x$ 以 Shamir 方式共享；各方通过对签名算法运行 MPC，联合产生 $m$ 上的有效签名。这对 **Schnorr/EdDSA/BLS**（线性签名）很容易，对 ECDSA 则较难（非线性求逆——可用基于 Paillier/LWE 的预处理或 GG18/CGGMP 风格协议解决）。
- **阈值 KEM/解密：** 各方联合解密或解封装。
- **分布式密钥生成（DKG）**与**主动刷新**（定期重新共享密钥，使慢速攻击者无法随时间累积到 $t$ 个份额）对部署至关重要。

## 5. 安全意义小结

1. **份额新鲜度** —— 阈值密钥必须**主动刷新**；否则长期使用的密钥终将被逐个份额地窃取。
2. **让模型匹配敌手** —— 不要把诚实多数协议的安全性声称为不诚实多数场景下的安全性。
3. **ECDSA 阈值很微妙** —— 应使用经过审计的协议（CGGMP；Schnorr 用 FROST），而非临时构造。
4. **中止处理** —— 许多 MPC 协议允许中止式拒绝服务；应用需要可识别中止或鲁棒性。
5. **量子威胁** —— OT 与 SPDZ 风格协议常基于经典假设（DDH、LWE）；基于 LWE 的 MPC 仍是后量子的，基于 DDH 的则不是。
