MITRE ATT&CK® 是一个全球可访问的知识库，收录**基于真实观测的攻击者战术与技术**。它是描述攻击行为的实际通用语言，被政府、产业界以及安全产品/服务社区广泛用于威胁建模、检测工程与红队规划。

## 核心数据模型

ATT&CK 是一张沿两个轴组织的矩阵：

- **战术（Tactics）**——*为什么*：攻击者的短期战术目标（如初始访问、持久化、数据外发）。战术有稳定 ID，如 `TA0001`。
- **技术（Techniques）**——*怎么做*：达成某战术的具体方法（如 T1566 *钓鱼*、T1078 *有效账户*）。技术 ID 形如 `T1059`。
- **子技术（Sub-techniques）**——技术的细分，记作 `T####.###`（如 T1059 *命令与脚本解释器* 下的 `T1059.001` *PowerShell*）。
- **过程（Procedures）**——特定**组织**或**软件**对某技术的具体实现（CTI 层）。

该模型是*基于行为*的：同一技术可由许多不同的恶意样本实现；ATT&CK 把「攻击者做什么」与「他们用什么工具」解耦。

## 三张矩阵

ATT&CK 提供三个技术领域的矩阵：

1. **Enterprise（企业）**——Windows、macOS、Linux、云（SaaS/IaaS）、容器、网络设备，以及身份/AD。规模最大、使用最广。
2. **Mobile（移动）**——Android 与 iOS。
3. **ICS**——工业控制系统（OT/SCADA）。

本领域知识库聚焦 **Enterprise**（见《企业战术》笔记）。

## 矩阵之外

ATT&CK 不止是一张矩阵，它还有配套领域：

| 领域                        | 内容                                 | 用途           |
| --------------------------- | ------------------------------------ | -------------- |
| **战术 / 技术**             | 矩阵本身                             | 描述行为       |
| **缓解措施（Mitigations）** | 对抗技术的企业安全控制               | 防御           |
| **检测（Detections）**      | 检测策略、分析（类 SIGMA）、数据组件 | 检测工程       |
| **CTI**                     | 组织、软件、行动                     | 归因与威胁情报 |
| **资产（Assets）**          | 技术所针对的资产/技术栈              | 范围界定       |

### 数据组件与检测

ATT&CK 明确把**数据源 → 数据组件 → 遥测**建模为「技术」与「防御者能检测到什么」之间的桥梁。每项技术都会列出可能暴露它的数据组件（如「进程创建」「文件修改」「网络流量」）。这正是 ATT&CK 成为现代检测工程基石的原因：它把「攻击者行为」转化为「日志查询」。

## 如何阅读一项技术

对每项技术，始终问四个问题：

1. **前置条件**——攻击者必须已具备什么访问权限/位置？
2. **机制**——该技术在技术层面如何运作？
3. **遥测**——哪些日志/事件（数据组件）会记录该行为？
4. **检测机会**——什么查询、异常或关联能把它暴露出来？

把 ATT&CK 简化成一张技术清单没有意义；每一条目都按「前置条件→机制→遥测→检测」的结构处理。

## ATT&CK 的版本演进

ATT&CK 持续更新（每年多次发布）。2026-08-17 抓取的在线企业矩阵列出 **15 个战术**，其中包括较新的 *Stealth（隐蔽）* 与 *Defense Impairment（防御削弱）* 战术，它们拆分了历史上统称的「防御规避」。由于技术与战术 ID 稳定但内容会演进，请始终以在线矩阵为准进行核对。
