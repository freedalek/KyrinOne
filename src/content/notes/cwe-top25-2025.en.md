The 2025 CWE Top 25 ranks the most common and impactful software weaknesses behind **39,080 CVE records** in the 2025 dataset. Ranks are driven by a composite **score** that blends prevalence, severity (average CVSS), and active exploitation (CISA KEV presence), not raw CVE counts alone. "CVEs in KEV" = how many CVE records referencing that weakness appear in CISA's Known Exploited Vulnerabilities catalog. "Rank Change" is versus the 2024 list.

## Reading the List Offensively

Three clusters dominate, and they map directly to offensive tradecraft:

### Cluster A — Web (the top of the list)
CWE-79 (XSS), CWE-89 (SQLi), CWE-352 (CSRF), CWE-22 (path traversal), CWE-434 (file upload), CWE-918 (SSRF), CWE-639 (IDOR), CWE-862/863 (missing/incorrect authz), CWE-306 (missing authn). These are the bread-and-butter of web pentesting (see 05_OWASP/OWASP-Top10-2025.md and 06_Web-Attacks/). Note that **access-control weaknesses (862/863/639/306/284) together outnumber almost any single injection** — consistent with OWASP A01 "Broken Access Control" being #1.

### Cluster B — Memory Safety (native code / pwn)
CWE-787 (OOB write), CWE-416 (use-after-free), CWE-125 (OOB read), CWE-120/121/122 (buffer overflows), CWE-476 (NULL deref). These are the root causes behind the overwhelming majority of exploitable memory-corruption bugs and are the domain of the `pwn` and `reverse-engineering` domains.

### Cluster C — Injection & Design
CWE-78 (OS command injection), CWE-94 (code injection), CWE-77 (generic command injection), CWE-502 (deserialization), CWE-20 (input validation), CWE-200 (info disclosure), CWE-770 (resource exhaustion/DoS).

## Notable Moves vs. 2024

- **CWE-79 XSS** holds #1 with a score (60.38) more than double #2 — the single most pervasive weakness.
- **Missing Authorization (CWE-862)** jumped +5 into the top 4 — a sharp signal that IDOR/authorization bugs are the fastest-growing web risk, matching OWASP's A01 emphasis.
- **NULL Pointer Dereference (CWE-476)** jumped +8 (into #13), and **Missing Authentication (CWE-306)** +4 (into #21).
- **Classic/Stack/Heap buffer overflows (CWE-120/121/122)** re-entered as distinct entries (marked N/A last year), indicating a re-disaggregation of memory-corruption reporting.
- **Command injection (CWE-77)** fell −10, and **Improper Input Validation (CWE-20)** fell −6.

## Why This Matters for Defenders

MITRE frames the Top 25 as *investment guidance*: because a small set of root causes drives most real-world compromise, eliminating them at the SDLC/architecture level removes entire classes of defect. For each weakness, ask: which ATT&CK technique triggers it, which CAPEC pattern exploits it, and which CVSS-detectable consequence results.
