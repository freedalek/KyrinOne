## 1. 侦察（TA0043）—— 12 项技术

**目标 / 前置条件。** 发生在任何立足点之前，完全从攻击者自身的基础设施发起。无需访问受害者系统；攻击者只需联网与时间。

**技术。** T1595 主动扫描（IP 段 / 漏洞 / 字典）、T1592 收集受害者主机信息、T1589 收集受害者身份信息、T1590 收集受害者网络信息、T1591 收集受害者组织信息、T1598 信息钓鱼、T1597 搜索封闭来源、T1596 搜索开放技术数据库（DNS、WHOIS、证书、CDN）、T1593 搜索开放网站/域名、T1594 搜索受害者自有网站、T1682 查询公共 AI 服务、T1681 搜索威胁厂商数据。

**机制。** 被动（WHOIS、被动 DNS、证书透明度、搜索引擎、公开代码仓库）与主动（端口/服务扫描、对子域名/URL 的字典爆破）。

**遥测。** 来自*外部*的侦察对受害者内部日志大多不可见——信号存在于*外部*遥测中：DNS 查询日志、Web 服务器访问日志（针对面向公众资产的扫描）、边界防火墙/IDS 日志。

**检测。** 体量启发式（404 突发、大量子域名查询）、非浏览器 User-Agent 聚集、证书透明度监控、蜜罐/诱饵资产。把访问前的侦察与之后来自同一源 IP 的初始访问关联起来。

## 2. 资源开发（TA0042）—— 9 项技术

**目标 / 前置条件。** 构建攻击手段：基础设施、账户与载荷。无需受害者访问；只需攻击者侧资源（或攻陷第三方）。

**技术。** T1583 获取基础设施、T1586 攻陷账户、T1584 攻陷基础设施、T1587 开发能力、T1585 建立账户、T1588 获取能力、T1608 准备能力、T1650 获取访问、T1683 生成内容。

**机制。** 注册域名/VPS/僵尸网络、购买凭据/漏洞利用、构建恶意软件、搭建钓鱼/恶意广告/SEO 投毒基础设施。

**检测。** 对受害者而言多为带外信号：域名信誉、对新注册且形似品牌的域名的被动 DNS、仿冒域名检测，以及针对已准备恶意软件的第三方威胁情报。内部：留意代理/DNS 日志中新出现的外部域名。

## 3. 初始访问（TA0001）—— 11 项技术

**目标 / 前置条件。** 获得首个立足点。前置条件：侦察与已准备的基础设施；执行路径各异（外部漏洞利用 vs. 用户交互）。

**技术。** T1566 钓鱼（鱼叉附件/链接/服务/语音）、T1190 利用面向公众的应用、T1133 外部远程服务、T1078 有效账户（默认/域/本地/云）、T1195 供应链攻陷、T1199 可信关系、T1189 路过式攻陷、T1200 硬件添加、T1091 通过可移动介质复制、T1669 Wi-Fi 网络、T1659 内容注入。

**机制（三大类）。**
- *钓鱼*——投递恶意附件或链接，依赖用户执行（见 T1204 用户执行）。
- *利用面向公众的应用*——滥用互联网可达应用（Web、VPN、邮件网关）中的漏洞来运行代码。这是 CVE/CWE/CAPEC 的典型桥接点。
- *有效账户*——用窃取/默认凭据登录，完全绕过漏洞利用。

**遥测。** 邮件网关判定（针对钓鱼）、Web/应用服务器访问日志（针对 T1190）、VPN/远程访问认证日志（针对 T1133/T1078），以及点击后的端点进程创建。

**检测。** 检测*第一个动作*而非访问本身：利用后的进程派生（异常的父→子）、来自异常源 IP/地理位置的登录、应用崩溃→shell 的关联，以及公共服务器上 Web Shell（T1505.003）的突然出现。

## 4. 执行（TA0002）—— 20 项技术

**目标 / 前置条件。** 在系统上运行攻击者代码。前置条件：某种立足点，或用户无意间触发的投递机制。

**技术。** T1059 命令与脚本解释器（PowerShell、Windows 命令外壳、Unix Shell、Python、JavaScript、Visual Basic、AppleScript、云 API 等）、T1204 用户执行、T1203 利用客户端执行、T1106 原生 API、T1569 系统服务、T1053 计划任务/作业、T1047 Windows 管理规范、T1127 受信开发工具代理执行（MSBuild 等）、T1574 劫持执行流、T1559 进程间通信、T1648 无服务器执行、T1674 输入注入、T1677 投毒流水线执行等。

**机制。** 脚本引擎与操作系统原生 API 是主力：攻击者更偏好 `powershell`、`cmd`、`sh`、`python` 或 `wmic`，而非投放编译后的二进制，因为它们已签名、无处不在，且紧邻日志记录。

**遥测。** 进程创建（最丰富的信号）、命令行日志、脚本块日志（PowerShell）、Sysmon 事件、EDR 进程血缘。

**检测。** 命令行分析：可疑参数（`-enc`、`IEX`、base64 块）、混淆、脚本引擎发起网络连接，以及异常的父→子对（如 Word 派生 PowerShell → 很可能为宏）。与 T1027 混淆文件/信息关联。

## 5. 持久化（TA0003）—— 22 项技术

**目标 / 前置条件。** 在重启、注销与凭据轮换后仍存活。前置条件：在主机上执行代码。

**技术。** T1547 开机或登录自启动执行（注册表 Run 键、Winlogon Helper、LSASS 驱动等）、T1053 计划任务/作业（cron、systemd 定时器、`at`）、T1543 创建或修改系统进程（Windows 服务、systemd、LaunchDaemon）、T1546 事件触发执行（WMI 事件订阅、shell 配置、辅助功能、AppInit DLL…）、T1136 创建账户、T1098 账户操纵（SSH authorized_keys、云角色）、T1137 Office 应用启动、T1505 服务器软件组件（Web Shell）、T1556 修改认证进程、T1542 预启动等。

**机制。** 挂接操作系统/应用众多自启动机制之一：注册表 `Run` 键、启动文件夹、服务、启动代理/守护进程、计划任务、shell 配置文件，或替换认证组件（密码过滤 DLL、PAM、SSP）。

**遥测。** 注册表修改、服务/守护进程创建、计划任务创建、自启动目录写入、账户创建，以及在已知自启动位置的文件创建。

**检测。** 监控自启动产物的*创建*（新 Run 键、新服务、新 `cron` 条目）而非其执行；对已知良好自启动建立基线并告警差异。Web Shell 通过 Web 根目录中的异常文件写入与异常 HTTP 请求模式检测。

## 6. 权限提升（TA0004）—— 13 项技术

**目标 / 前置条件。** 从普通用户 → 管理员/SYSTEM/root/域管。前置条件：较低权限的立足点。

**技术。** T1548 滥用提权控制机制（setuid/setgid、绕过 UAC、Sudo 缓存）、T1134 访问令牌操纵（令牌模拟、父 PID 伪造、SID-History）、T1055 进程注入（DLL 注入、进程镂空、APC、Ptrace）、T1068 利用提权（内核/OS CVE）、T1053 计划任务/作业（以 SYSTEM 运行）、T1611 逃逸到宿主（容器逃逸）、T1574 劫持执行流（未加引号的服务路径、DLL 劫持）、T1484 域/租户策略修改。

**机制。** 三个族：(a) 滥用配置错误的提权机制（服务文件权限薄弱、未加引号路径、sudo 规则），(b) 利用内核/OS 漏洞，(c) 窃取更高权限的令牌/上下文（模拟、注入）。

**遥测。** 带权限转换的进程创建、令牌/权限审计、服务配置变更、内核事件日志。

**检测。** 对进程生命周期中的完整性级别/uid 变化、令牌模拟事件、服务二进制路径变更，以及高权限父进程的异常子进程告警。对漏洞利用，匹配 CVE 特定签名。

## 7. 隐蔽（TA0005）—— 30 项技术

**目标 / 前置条件。** 向分析人员与自动化工具隐藏活动。前置条件：持续存在。

**技术。** T1564 隐藏痕迹（隐藏文件、NTFS ADS、隐藏用户、VBA stomping）、T1027 混淆文件或信息（加壳、base64、命令混淆、无文件）、T1036 伪装（重命名合法工具、双扩展名、RLO）、T1140 去混淆/解码、T1055 进程注入（亦为提权机制）、T1497 虚拟化/沙箱规避、T1480 执行护栏（环境绑定）、T1620 反射式代码加载、T1218 系统二进制代理执行（regsvr32、rundll32、mshta —— LOLBin）、T1553 颠覆信任控制（代码签名、根证书安装、MOTW 绕过）、T1070 痕迹清除、T1679 选择性排除等。

**机制。** 就地取材（滥用已签名的 OS 二进制）、混淆/加壳、内存中的无文件执行，以及伪装文件/进程以显得合法。

**遥测。** 脚本块/命令行内容、文件哈希偏离、以异常参数调用已签名二进制、镜像加载事件。

**检测。** 这是 EDR/行为分析发挥价值之处：命令行混淆熵、LOLBin 父子异常、已签名进程加载未签名代码，以及已知双用途二进制以网络/脚本参数被调用。

## 8. 防御削弱（TA0112）—— 18 项技术

**目标 / 前置条件。** 削弱受害者检测或响应的能力。前置条件：足以触碰安全工具/日志的权限。

**技术。** T1562/T1685 禁用或修改工具（禁用 AV/EDR、清除事件日志、禁用云日志/auditd）、T1562 削弱防御（历史归属）、T1222 文件与目录权限修改、T1484 域/租户策略修改、T1556 修改认证进程、T1601 修改系统镜像、T1686 禁用或修改系统防火墙、T1600 削弱加密、T1689 降级攻击、T1687 利用防御削弱、T1207 恶意域控制器。

**机制。** 停止服务、清除/轮换日志、削弱加密、修改 GPO、禁用防火墙，或直接修补 OS 镜像。

**遥测。** 服务停止事件、审计日志清除事件、安全策略变更，以及预期遥测的*缺失*（本身即为检测信号）。

**检测。** 对任何事件日志清除、AV/EDR 服务停止、防火墙规则删除或 GPO 修改告警。把端点遥测流中的突然静默视为高严重性。

## 9. 凭据访问（TA0006）—— 17 项技术

**目标 / 前置条件。** 获取密码、哈希、令牌、票据。前置条件：在主机上执行，通常需本地管理员权限以进行转储。

**技术。** T1110 暴力破解（口令猜测/破解/喷洒/填充）、T1003 OS 凭据转储（LSASS 内存、SAM、NTDS、LSA 机密、DCSync、`/etc/shadow`）、T1558 窃取或伪造 Kerberos 票据（黄金/白银票据、Kerberoasting、AS-REP Roasting）、T1555 从密码存储获取凭据（浏览器、凭据管理器、钥匙串、机密管理器）、T1552 未受保护的凭据（文件、注册表、shell 历史、云元数据 API、GPP）、T1040 网络嗅探、T1056 输入捕获（键盘记录）、T1111/T1621 MFA 拦截/请求生成、T1528 窃取应用访问令牌、T1539 窃取 Web 会话 Cookie、T1649 窃取/伪造认证证书、T1187 强制认证、T1212 利用凭据访问。

**机制（AD 要点）。** 转储 `lsass.exe` 以获取明文/NTLM、提取 `NTDS.dit` 以获取域哈希、通过 DCSync 请求复制机密、Kerberoasting（请求 SPN 票据并离线破解），以及传递哈希/票据以重用。

**遥测。** 对敏感进程的访问（Sysmon LSASS 访问）、DC 复制事件、Kerberos TGS 请求异常、认证失败量（喷洒）、异常文件访问（`/etc/shadow`）。

**检测。** 对非受保护进程访问 LSASS、Kerberoasting（对弱加密类型 SPN 的 TGS 请求）、口令喷洒特征（多账户、单密码、随时间铺开）与 DCSync（意外的 `DRSUAPI` 复制）告警。

## 10. 发现（TA0007）—— 34 项技术

**目标 / 前置条件。** 摸清环境以规划下一步。前置条件：立足点。

**技术。** T1087 账户发现、T1082 系统信息发现、T1016 系统网络配置发现、T1018 远程系统发现、T1046 网络服务发现、T1135 网络共享发现、T1069 权限组发现、T1007 系统服务发现、T1057 进程发现、T1012 查询注册表、T1482 域信任发现、T1526 云服务发现、T1613 容器与资源发现、T1580 云基础设施发现等。

**机制。** 通过 OS/云 API 枚举：`whoami`、`net user /domain`、`ipconfig`、`nltest`、`BloodHound` 式图谱收集、云元数据/服务枚举。

**遥测。** 单一账户突发只读枚举命令、异常查询量、云 API `List*`/`Describe*` 调用模式。

**检测。** 对每账户枚举建立基线；对短窗口峰值、非管理员账户枚举域，以及已知侦察工具命令行（如 BloodHound/SharpHound 收集器）告警。

## 11. 横向移动（TA0008）—— 9 项技术

**目标 / 前置条件。** 从一台已攻陷主机转向其他主机。前置条件：凭据或针对远程服务的漏洞利用。

**技术。** T1021 远程服务（RDP、SMB/管理共享、DCOM、SSH、VNC、WinRM、云服务）、T1550 使用替代认证材料（传递哈希、传递票据、应用访问令牌、Web 会话 Cookie）、T1210 利用远程服务、T1570 横向工具传输、T1563 远程服务会话劫持、T1534 内部鱼叉钓鱼、T1091 通过可移动介质复制、T1080 污染共享内容。

**机制。** 用窃取的材料认证远程服务或利用它，然后把工具（T1570）传输到新主机。传递哈希/票据在无需明文口令的情况下重用凭据材料。

**遥测。** 主机间的新登录类型（类型 3/10）、使用已知已攻陷材料的认证、SMB/RDP/WinRM 连接日志、远程共享上工具的文件创建。

**检测。** 对工作站→工作站的管理员登录（异常来源）、PtH 特征（无交互登录的 NTLM），以及已知双用途工具经 SMB/管理共享的横向传输告警。

## 12. 收集（TA0009）—— 17 项技术

**目标 / 前置条件。** 汇集有价值的数据。前置条件：可访问目标数据存储。

**技术。** T1005 本地系统数据、T1039 网络共享驱动器数据、T1530 云存储数据、T1213 信息仓库数据（SharePoint、Confluence、代码仓库、数据库）、T1114 邮件收集（含邮件转发规则）、T1056 输入捕获、T1113 屏幕捕获、T1560 归档收集数据、T1074 数据暂存、T1025 可移动介质数据、T1602 配置仓库数据。

**机制。** 读取文件、查询数据库/仓库、截屏、捕获按键，然后把战果暂存/压缩（T1560 归档）到暂存目录（T1074）。

**遥测。** 大规模文件读取/打开模式、归档工具调用（7z/zip/tar）、异常云存储 API `Get*` 量、邮箱转发规则创建。

**检测。** 对批量文件访问异常、归档后不久的外发传输（链接到数据外发），以及邮箱规则创建（经典的收集+持久化信号）告警。

## 13. 命令与控制（TA0011）—— 18 项技术

**目标 / 前置条件。** 维持对已攻陷资产的控制通道。前置条件：在主机上执行且网络可出站。

**技术。** T1071 应用层协议（HTTP/HTTPS、DNS、邮件）、T1573 加密通道、T1572 协议隧道、T1090 代理（含域前置）、T1568 动态解析（Fast Flux、DGA）、T1105 入口工具传输、T1219 远程访问工具、T1008 备用通道、T1104 多级通道、T1095 非应用层协议、T1571 非标准端口、T1132 数据编码、T1001 数据混淆、T1205 流量信令（端口敲门）。

**机制。** 通过常见协议发送信标以混入正常流量，加密/隧道化，并用动态解析（DGA 域名）或代理以抵抗封锁/下线。

**遥测。** DNS 查询模式（DGA 的 NXDOMAIN 风暴、过长/子域名密集的查询）、代理/Web 过滤日志、异常信标（周期性、低抖动）、异常进程的出站连接。

**检测。** 通过 NXDOMAIN 熵与域名词法分析检测 DGA；通过 netflow/代理上的周期性分析检测信标；通过非标准端口上的异常流量检测协议隧道；通过向可疑位置下载可执行文件检测入口工具传输。

## 14. 数据外发（TA0010）—— 9 项技术

**目标 / 前置条件。** 把收集的数据移出。前置条件：已暂存收集数据 + 出站通道。

**技术。** T1041 经 C2 通道外发、T1567 经 Web 服务外发（云存储、网页邮箱）、T1020 自动化外发、T1011 经其他网络介质外发、T1048 经替代协议外发（HTTP/DNS/SMB）、T1052 经物理介质外发、T1041/C2 通道重用。

**机制。** 重用 C2 通道或滥用受认可通道（云存储 API、邮件）把数据推出，常以分块、压缩或定时（T1020）方式混入正常流量。

**遥测。** 出站字节量异常、非浏览器进程向云存储域名的上传、载荷异常大/长的 DNS 查询（DNS 外发）。

**检测。** 按主机/账户对照基线跟踪出站量；检测经异常协议离开的数据（高熵的 DNS TXT、向外部发送的 SMB）；把大规模内部收集（§12）与随后的出站突发关联起来。

## 15. 影响（TA0040）—— 15 项技术

**目标 / 前置条件。** 破坏可用性或完整性（勒索、擦除、DoS）。前置条件：足够权限；通常是终末阶段。

**技术。** T1486 为影响加密数据（勒索软件）、T1485 数据销毁、T1490 抑制系统恢复（删除卷影副本/备份）、T1498 网络拒绝服务、T1491 涂改、T1489 服务停止、T1495 固件损坏、T1561 磁盘擦除、T1529 系统关机/重启等。

**机制。** 加密/擦除数据，先摧毁备份（以迫使支付赎金），随后中断服务。

**遥测。** 大规模文件写入/重命名/加密突发、卷影副本删除命令（`vssadmin delete shadows`）、备份工具交互。

**检测。** 对批量文件扩展名变更、卷影副本删除、备份篡改，以及快速的类加密 I/O 告警——最好配合自动隔离/剧本响应，因为「影响」是阻止攻击的最后机会。

## 跨战术关系（攻击链推理）

- **初始访问 → 执行**：T1566 钓鱼需要 T1204 用户执行才能落地代码。
- **执行 → 持久化**：代码执行会写入自启动产物（T1547/T1053）。
- **持久化 → 权限提升**：许多自启动同时也提权（以 SYSTEM 运行的服务）。
- **凭据访问 → 横向移动**：转储的哈希/票据（T1003/T1558）经 T1550 重用。
- **收集 → C2 → 数据外发**：暂存数据（T1074）搭乘 C2 通道出去（T1041）。
- **隐蔽/防御削弱** 贯穿整条链*并行*运行，保护其他每个阶段。
- **发现** 持续运行，为每一次后续转向决策提供输入。
